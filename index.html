Lightweight demo for GitHub Pages and Actions

This repository hosts a minimal static site and a CI workflow to lint HTML and deploy to GitHub Pages.

Preview locally

Quick facts

Location: week8_github_action

Use the workflow in .github/workflows/deploy.yml to auto-deploy on push to main.

Features

Responsive

Adaptable layout with no dependencies.

CI Linting

Workflow runs HTMLHint to catch syntax issues.

Deployable

Configured to publish to GitHub Pages via Actions.

Preview locally
